# 钉钉参数自动登录

- Requirement ID: REQ-2026-002
- Project ID: PRJ-WEKNORA-VONE
- Owner: ROCKL
- Priority: P2
- Requested At: 2026-10-13T09:18:00+08:00
- Time Basis: 首次正式登记时间，不反推历史聊天时间
- Source: 用户在本会话确认“采用这个模式进行优化处理”。
- Requirement Ready Gate: PASS

## 范围

仅在 /login?autologindingtalk=true 主动触发现有钉钉登录；普通 /login 不变。复用企业内免登与浏览器 OAuth，不更改身份绑定、权限、Token、API 或数据库。参数只消费一次，保留其他 query/hash；失败后允许手动重试，不自动循环。

## 非范围

不绕过钉钉授权确认，不修改开放平台首页配置，不新增 SDK，不合并账号，不修改现有邀请注册流程。

## 验收标准

- AC1: 精确 true 才触发；缺省/false/重复值不触发。
- AC2: 等待钉钉配置，启用后自动调用现有登录处理器一次。
- AC3: 失败/禁用后移除入口参数，刷新不会反复发起；手动按钮仍可用。
- AC4: 已登录、回调处理中、注册/邀请或离开登录页时不抢占既有流程。
- AC5: 浏览器无桥接走既有 OAuth；钉钉桥接存在时复用免登，配置/凭据不进入 URL。
- AC6: 定向单测、类型检查、构建及模拟浏览器验证通过；真实钉钉账号验收单独记录。
