# WeKnora Vone 研发治理目录

本目录是当前项目需求、任务、变更、发布与验证证据的文档事实源。

- `registers/`：项目级结构化台账；`project-board.md` 由检查工具生成，不手工维护。
- `requirements/`：正式需求正文。
- `tasks/`：审批进入实施阶段后，按 Task ID 建立独立任务状态目录。
- `plans/`、`changes/`、`releases/`：分别保存实施计划、需求变更和发布清单。
- `history/events/`、`history/snapshots/`：保存状态变更事件和派生快照。
- `runtime/`：本地运行态文件，不作为正式证据提交。
