# 知识库项目结构左侧树形导航调整

## Governance Context

- Project ID: PRJ-WEKNORA-VONE
- Requirement ID: REQ-2026-001
- Task ID: TASK-20260817-FE-ROCKL-01
- Task Type: Feature Amendment
- Target Release: VONE-0.7.2.1
- Approved By: ROCKL
- Approved At: 2026-08-21
- Process Profile: Standard for this UI-only amendment; the parent requirement remains Controlled

## 变更目标

将 `/platform/knowledge-bases` 顶部横向排列的“项目结构”调整为左侧树形导航，使项目层级、展开收起和当前筛选范围更直观，并与知识库内部目录的操作语言保持一致。

## 变更前后对照

| 维度 | 当前 | 变更后 | 备注 |
| --- | --- | --- | --- |
| 位置 | 项目结构位于知识库卡片上方 | 左侧项目树、右侧知识库卡片 | 桌面端左树右卡片 |
| 层级 | 节点按深度缩进，但横向换行 | 节点纵向树形排列并支持展开收起 | 不改变项目数据结构 |
| 根节点 | “全部知识库”“未分类”并列 | “全部知识库”为虚拟根入口，“未分类”和项目节点纵向展示 | 数量语义保持不变 |
| 项目操作 | 顶部横向按钮 | 根项目使用顶部新增入口，节点操作集中到“更多”菜单 | 仅 Workspace Owner 可见 |
| 知识库归类 | 面板底部下拉框 | 继续在选中节点下提供归类入口 | 沿用现有接口 |
| 面板宽度 | 横向占满内容区 | 默认 260px，可收起为紧凑入口 | 不保存用户偏好 |

## 兼容性分类

- 类型：修改型前端变更。
- API：无新增、删除或字段变化。
- 数据库：无 Schema、迁移或存量数据变化。
- 权限：继续使用现有 Workspace Owner 前端门控；后端仍为最终权限边界。

## 影响半径

- 直接代码：`KBCollectionTreePanel.vue`、`KnowledgeBaseList.vue`、`collectionTree.ts` 及定向测试。
- 调用方：知识库全部、本空间、收藏、最近和共享空间卡片列表继续消费同一 `collectionFilterIds`。
- 数据：无。
- 配置：无。
- 接口契约：无。
- UI：知识库列表主滚动区、卡片可用宽度、树面板加载/错误/空态和窄屏布局。
- 测试：树展开折叠、子树计数、节点筛选、面板收起、空节点和 Owner 操作回归。

## 改动清单

1. 将知识库列表主区域改为左树右内容的双栏结构。
2. 为项目树增加可见节点展开状态，并保持选中节点筛选语义。
3. 将项目节点维护操作收口到节点上下文菜单。
4. 保留“未分类”归类和现有接口调用，不修改后端。
5. 补充树可见节点纯函数测试，并执行前端类型、测试、i18n 和生产构建检查。

## 风险与回滚

- 回归风险：中低；主要风险是列表滚动、卡片宽度和树节点操作事件冒泡。
- 发布顺序：仅前端候选镜像；不要求 App、数据库或迁移先行。
- 回滚方式：回退本次前端提交并重建前端镜像，现有项目树数据和接口不受影响。
- 升级影响：该组件属于 VONE 定制；后续上游升级需人工合并 `KnowledgeBaseList.vue`，新增定制组件文件可独立迁移。

## 验收标准

- [x] 项目结构固定展示在知识库卡片左侧，卡片列表位于右侧并独立滚动。
- [x] 多级项目节点纵向显示，父节点可展开和收起。
- [x] 点击项目节点后，右侧只显示该节点及其后代绑定的知识库。
- [x] 点击“全部知识库”恢复当前空间范围内的全部可见知识库。

- [x] Workspace Owner 可创建根/子项目并维护节点；非 Owner 不显示维护操作（代码/权限门控验证；真实账号矩阵待独立 QA）。

- [x] 现有 API、ACL、数据库迁移和知识库内部 `folder_path` 不发生变化。
