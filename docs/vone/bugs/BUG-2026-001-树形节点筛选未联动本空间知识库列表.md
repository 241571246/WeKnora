# BUG-2026-001 树形节点筛选未联动本空间知识库列表

## 发现环境

- 发现阶段：本地候选版本手工验收（UAT）
- 目标版本：VONE-0.7.2.1
- 候选提交：`3693b7990176217304bc921bd01f422a8f1d5a55`
- 页面：知识库 / 本空间 / 项目结构
- 报告人：ROCKL

## 复现步骤

1. 进入知识库页面并选择“本空间”。
2. 在“项目结构”中选择知识库数量为 1 的节点“VCOS-游轮运营管理系统”。
3. 查看节点下方的知识库卡片列表。

## 实际结果

节点高亮且数量显示为 1，但下方仍显示本空间的 3 个知识库卡片。

## 期望结果

选择树节点后，只显示绑定到该节点或其后代节点的知识库；本例应只显示 1 个知识库。

## 技术定位

- `KBCollectionTreePanel.vue` 已正确发出筛选知识库 ID。
- `KnowledgeBaseList.vue` 已将该事件写入 `collectionFilterIds`，也存在 `filteredKnowledgeBases` 派生结果。
- “本空间”模板和分组计数继续直接使用 `sortedMineKbs`，未消费集合筛选结果。
- 节点计数正确，说明集合绑定与后端读取链路可用；故障位于前端列表派生状态和模板消费不一致。

## 修复范围

- 为知识库 ID 集合筛选增加可测试的纯函数。
- “本空间”列表、分组数量及空状态统一消费筛选后的结果。
- 补充未筛选、单节点筛选和空节点筛选测试。
- 不修改 ACL、集合绑定、数据库迁移及知识库内容数据。

## 验收标准

- 选择数量为 1 的节点时只显示 1 个对应知识库。
- 选择“全部知识库”时恢复显示全部可见知识库。
- 选择无绑定知识库的节点时显示空结果，不回退到全部列表。
- 已有收藏、最近和权限行为不受影响。
